# Getting Started with Create React App

my-dashboard is a responsive dashboard built with React and Redux, featuring user data fetched from a public API. It includes user stats, active/inactive users, search, pagination, and modern skeleton loading animations.

## **Getting Started**

Follow these steps to run the project locally:


1) Install dependencies:

npm install

2) Start the development server:

npm start

    Open in browser:
    Go to http://localhost:3000

to view the dashboard.
